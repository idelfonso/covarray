# Security Policy

## Supported versions

covarray is pre-1.0 and has no stable release yet. Security fixes land on
`main` only.

## Reporting a vulnerability

Please do not open a public issue for a security vulnerability. Instead,
use GitHub's private vulnerability reporting for this repository:
[Report a vulnerability](https://github.com/idelfonso/covarray/security/advisories/new).

You can expect an initial response within a few days.
